# AI Job Finder

AI-powered job search tool that understands natural-language job requests, searches real job listings, filters them based on user requirements, and ranks the most relevant jobs using AI.

## Features

- Natural-language job search
- AI-powered request parsing
- Search jobs using JSearch API
- Filter jobs by:
  - Technology / stack
  - Number of jobs
  - Posting date
  - Location
  - Employment type
  - Excluded job sources
- AI-powered job relevance analysis
- Relevance score from 0–100
- Extracts actual job requirements and technologies
- Sorts jobs by relevance
- Conversational memory for follow-up requests
